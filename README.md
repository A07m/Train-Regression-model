# Linear Regression Analysis

This project demonstrates a complete Linear Regression analysis using Python.

## Project Overview

The analysis covers:

- Data inspection and descriptive statistics
- Correlation and regression analysis
- Linear Regression using Scikit-learn
- Regression coefficient (slope)
- Intercept calculation
- R-squared evaluation
- Regression visualization
- Statistical regression analysis using Statsmodels
- Confidence intervals
- Predicted values
- Actual vs. predicted values comparison

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn
- Statsmodels

## Regression Model

The project uses a simple linear regression model:

Y = β₀ + β₁X + ε

Where:

- Y = Dependent Variable
- X = Independent Variable
- β₀ = Intercept
- β₁ = Regression Coefficient (Slope)
- ε = Error Term

## Analysis

The project calculates:

- Regression coefficient
- Intercept
- R-squared
- Statistical regression summary
- Confidence intervals
- Predicted Y values

It also visualizes the relationship between X and Y using a regression plot and compares actual values with predicted values.
